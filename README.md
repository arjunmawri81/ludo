# 🎲 Ludo King Mirror Pro Tracker (GODMODE v3)

A high-performance, 100% client-side Ludo AI decision advisor and live board mirror. Built with pure Vanilla HTML5/CSS/JS with zero backend or database dependencies. Works completely offline as a PWA.

## 🚀 Features
- **Zero-Scroll Dynamic Layout**: 100% viewport fit (`100dvh`) optimized for mobile and desktop screens.
- **⚡ 1-Hand Dock Mode**: Puts both Opponent and Player dice in the bottom thumb zone for lightning-fast input.
- **GODMODE v3 Engine**: 12-layer tactical lookahead evaluator (Expectimax 3-ply, Golden Distance 7-8, Ambush traps, Wall Blockades, Predatory Hunter).
- **💥 Official 6-6-6 Bust Rule**: Automatic detection and forfeit alerts for 3 consecutive sixes.
- **🎮 Multi-Mode Support**: Supports Classic Tournament and Zupee Points Rush modes.
- **Offline PWA**: Full ServiceWorker support, installable on mobile homescreen.

## 🛠️ Tech Stack
- HTML5 / CSS3 / ES6 JavaScript
- Pure Vanilla - Zero external libraries or frameworks
- Zero backend required (1-click deploy to Vercel, Netlify, or GitHub Pages)
